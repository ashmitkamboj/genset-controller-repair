# Genset Controller Repair

The website homepage for Electronic Repair Services, a genset controller repair and refurbishment business.

## Scope

The current implementation includes the homepage, navigation, About Us section, repair information, testimonials placeholder, contact details, footer, and local image assets.

The project currently has no backend, database, or API.

## Technology

- Next.js App Router
- TypeScript
- React
- Tailwind CSS
- React Compiler

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
npm run start
```

## Project Structure

```text
src/app/                App Router page, layout, and global styles
src/components/         Homepage components
```
